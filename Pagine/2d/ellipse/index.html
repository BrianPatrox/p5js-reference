ellipse()

Draws an ellipse (oval).

An ellipse is a round shape defined by the x, y, w and h parameters. x and y set
set the location of the arc's center. w and h set its width and height. See ellipseMode() for other
ellipse() ways to set its position.

If no height is set, the value of width is used for both the width and height. If a negative
height or width is specified, the absolute value is taken.
