line()

Draws a straight line between two points.

A line's default width is one pixel. The version of line() with four parameters draws
the line in 2D. To color a line, use the stroke() function. To change its width, use the
strokeWeight() function. A line can't be filled, so the fill() function won't affect the line's
color.

The version of line() with six parameters allows the line to be drawn in 3D space.
Doing so requires adding the WEBGL argument to createCanvas().
